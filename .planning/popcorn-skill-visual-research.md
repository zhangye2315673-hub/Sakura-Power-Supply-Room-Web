# 爆米花机技能视觉调研与实现决策

更新时间：2026-08-25

## 目标

- 删除与爆米花语义不匹配的桃心王冠模型。
- 取消目标整根线持续发光，避免把“提示出口”误读为线缆强化或危险状态。
- 将技能反馈拆成两个连续节拍：生命上限增加的“加餐爆裂”，以及目标可抽插头附近的“出口标记”。
- 保持当前 SAKURA 赛璐璐低多边形风格，不引入大型运行时依赖。

## 在线方案核对

### Three.js `Points` / `PointsMaterial`

- 官方文档：
  - https://threejs.org/docs/#api/en/objects/Points
  - https://threejs.org/docs/#api/en/materials/PointsMaterial
- 官方示例：
  - https://threejs.org/examples/webgl_points_sprites.html
- 适合大量同质粒子、远景尘埃和连续喷射。
- 本技能只有少量近景、需要粗描边与明确爆米花轮廓的对象，点精灵会额外引入贴图、透明排序与朝向管理，因此本轮不采用。

### `three.quarks`

- 项目：https://github.com/Alchemist0823/three.quarks
- 提供发射器、行为、批处理和复杂粒子系统，适合大型特效管线。
- 当前需求只需要一次短爆裂和一个持续局部标记，引入完整粒子系统会放大包体、维护面和调试成本，因此不采用。

### `THREE.MeshLine`

- 项目：https://github.com/spite/THREE.MeshLine
- 适合有稳定屏幕宽度的曲线、抛物线拖尾和风格化描边。
- 可作为未来“爆米花从机器飞向生命 HUD”或抛物线轨迹的备选；本轮没有跨屏轨迹需求，不增加依赖。

## 当前实现决策

1. 使用原生 Three.js 网格创建三颗低多边形爆米花，每颗由四个十二面体奶油爆花瓣和一个六边形玉米芯组成；三颗按圆周 120° 等距排列。
2. 在目标可抽插头附近增加八段断续目标环和六根短射线，不改变线体本身的颜色或发光强度。
3. 持久提示继承当前可抽插头的世界方向，立体环面垂直于抽出方向，并沿该方向轻跳；环段继续使用顺序脉冲和射线呼吸，不再朝向相机。
4. 技能触发时只保留插头上的单个持久标记，不再用同一资产创建放大的瞬时副本，避免同时出现两个圆环。
5. 生命上限增加时由 HUD 播放七颗 CSS 爆米花颗粒爆裂，新生命格使用弹入动画。
6. 爆米花技能测试单独显示生命栏；其他技能测试继续沿用隐藏生命栏的既有规则。
7. 废弃资产：`popcorn-heart-crown`、`heart-cluster`、`prompt-crown`。

## 验收标准

- 生产资产列表、运行时代码和审阅脚本中不存在 `popcorn-heart-crown`；测试仅允许保留用于防回归的反向断言。
- 提示目标线的 `glowStrength` 保持为 `0`。
- 持久标记只出现一份，包含 3 颗按 120° 等距排列的爆米花、8 个有厚度的环段和 6 根射线，附着当前可抽插头位置，并与该端抽出方向对齐。
- 技能触发后最大生命从 3 增至 4，生命栏可见，新生命格和爆米花颗粒动画触发。
- 正确抽出提示目标后，旧目标对应标记立即消失。
