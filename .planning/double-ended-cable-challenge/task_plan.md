# 双线头随机挑战玩法计划

## 状态

- 设计状态：核心规则已确认
- 实现状态：已完成实现与自动验证
- 投放位置：总随机挑战池
- 首期随机权重：20%

## 1. 玩法定位

双线头随机挑战保留普通随机挑战的完整核心循环：

```text
观察中央线组
  → 选择一条线的某个插头
  → 从没有阻挡的一端抽出整条线
  → 使用该端插头连接家电
  → 播放家电动画并替换家电
  → 继续拆解剩余线组
```

本玩法只改变中央线组的判断方式，不改变后续家电连接、家电动画和家电替换规则。

## 2. 双插头核心规则

- 本局所有线都是双插头，不混入普通单插头线；
- 玩家先观察两个插头周围的空间，再主动选择从哪一端抽线；
- 插头当前没有受到阻挡，就可以从该端抽出；
- 插头当前受到阻挡，就不能从该端抽出；
- 可抽方向不是线条的固定答案，而是随剩余线组实时变化；
- 当阻挡它的其他线被移除后，原本不能抽的插头可以变为可抽；
- 一条线允许两端同时可抽、只有一端可抽或两端暂时都不可抽。

### 三种实时状态

| 状态 | 玩家可执行操作 |
|---|---|
| 两端都畅通 | 任意选择一端都能正确抽出 |
| 只有一端畅通 | 必须选择畅通端 |
| 两端都受阻 | 当前不能抽这条线，应寻找其他可抽线 |

## 3. 全局可解约束

允许单条线暂时两端都受阻，但不允许整个线组进入死局。

生成器必须保证：

- 任意有效拆解状态下，至少存在 1 个可抽插头；
- 玩家每次正确抽线后，剩余局面仍然存在后续解法；
- 玩家可以持续找到正确路线，直到全部线组被清空；
- 可解性来自生成阶段保证，不能依赖运行时偷偷修改阻挡关系。

## 4. 随机生成与难度目标

双线头不能直接由普通随机线组机械转换。普通单线头线组中原本朝外的线尾，在增加第二个插头后会形成大量无阻挡出口，导致挑战过于简单。

因此需要为双线头建立独立的随机生成约束：

- 从一条完整可行的拆解顺序反向构造线组；
- 通过交叠和出口遮挡制造依赖关系；
- 难度由“当前可抽插头数量”控制，而不是单纯增加线条数量；
- 同一条线两端都畅通时，按 2 条可抽路线计算；
- 大多数步骤保持 1～2 个可抽插头；
- 偶尔允许出现 3 个可抽插头，作为节奏缓冲；
- 首版不应频繁出现 3 个以上的可抽插头。

## 5. 内容规模

- 双线头挑战的线条总数，首版使用普通随机挑战的约 80%；
- 线条减少用于抵消双倍插头带来的视觉密度；
- 难度主要通过出口阻挡、拆解依赖和可选路线数量建立；
- 不通过堆满线条制造难以阅读的画面。

实际线条数量由普通随机挑战的当前配置计算，取整规则在实现阶段确定。

## 6. 生命值与错误反馈

完全沿用普通随机挑战规则：

- 开局 3 颗生命；
- 点击受到阻挡、无法抽出的插头时扣除 1 颗生命；
- 生命值归零后挑战失败；
- 错误时沿用普通线组的受阻回弹和扣心反馈；
- 不增加双线头专属文字解释；
- 不增加额外扣时或其他叠加惩罚。

## 7. 家电连接规则

- 玩家从哪个插头成功抽线，该插头就作为后续连接家电的活动端；
- 进入家电连接阶段后，完全沿用普通模式的线缆与插头显示；
- 不需要在家电连接阶段继续显示双头线；
- 不改变插入家电、家电通电动画和替换家电的现有流程。

## 8. 教学与提示

- 不修改现有 5 个教学关；
- 不增加双线头首次教学；
- 不增加规则弹窗或演示动画；
- 两端都显示插头，本身就是玩家可以从两端尝试抽线的视觉说明；
- 玩家通过现有的阻挡回弹和生命值反馈理解错误。

## 9. 随机池规则

- 双线头不设置主界面独立入口；
- 只从总随机挑战池中被随机选中；
- 首期权重设为 20%；
- 后续增加更多玩法后，再统一调整总随机池的权重分配；
- 完成挑战后的结算与下一轮流转沿用普通随机挑战。

- [x] 线条数量约为同档普通随机挑战的 80%；
- [x] 两端可抽性完全由实时阻挡关系决定；

- [x] 成功抽线后沿用普通家电连接、动画和替换流程；
