# RUSH 模式玩法计划

## 状态

- 设计状态：核心规则已确认
- 实现状态：难度曲线与末段视觉压力反馈已完成并通过验收（2026-08-10）
- 适用版本：樱色插线室改版

## 1. 模式定位

RUSH 不是替换“抽线 → 插入家电 → 家电反馈”的基础玩法，而是在解线之上增加单一的时间压力。

它是一种纯粹的速度挑战：玩家不需要处理房间、左右家电或家电动画，只专注于在规定时间内完成中央线组的拆解。

RUSH 同时存在两种入口：

1. 作为主界面的独立模式进入时，固定从第 1 关开始并按 1～10 顺序推进；
2. 作为总“随机挑战”中的一种规则被抽到时，仍从 10 张固定卡中随机选题。

## 2. 单局核心循环

```text
进入 RUSH
  → 开局提示本局固定线组和倒计时
  → 开始整局倒计时
  → 玩家快速拆解中央线组
  → 清完全部线组，或倒计时归零
  → 进入成功/失败结算
  → 独立 RUSH 进入下一关；总随机池 RUSH 返回下一轮随机挑战；或回到主界面
```

## 3. 挑战内容结构

首期设计 10 个固定 RUSH 线组，不使用完全随机生成。

每个 RUSH 线组是一张经过人工设计和测试的挑战卡，至少包含：

- `id`：固定挑战编号；
- 中央线组布局；
- 线组数量与连接关系；
- 预设倒计时；
- 设计难度标签；
- 可解性与几何安全性验证结果。

从主界面点击独立 RUSH 时固定加载 `rush-01`，通关后依次加载下一张固定卡。只有总随机挑战池抽到 RUSH 规则时，才从这 10 个固定线组中随机选取 1 个使用。

第 1、2 张卡是明确的热身例外，分别使用 20、22 条线；短线占比不少于 60%，不使用长线，平均转角不高于 2.2，让玩家先建立快速拆线节奏。第 3～10 张卡继续绑定 42、46、50 或 54 条线的随机挑战参考档，实际线数不得低于对应参考档的 80%，逐步增加到 44 条。

时间限制跟随挑战卡预设，不在运行时根据玩家表现动态调整。前两张热身卡缩短为 48、52 秒；后续卡在拆线操作时间之外增加 3D 旋转观察预算，逐步提高到 120 秒。

## 4. 视觉与场景范围

RUSH 场景只保留中央线组和必要的操作反馈：

- 不生成左右两侧家电；
- 不引入客厅、厨房等房间背景；
- 不播放普通模式中的家电展示动画；
- 重点突出线头、可拆解方向、剩余线组和倒计时；
- 顶部倒计时每秒进行一次缩放脉冲，最后约 8～12 秒持续增大，缩放峰值不超过原尺寸 2 倍，并始终锚定在屏幕顶部安全区；
- 最后 5 秒倒计时切换为更强的深红高危态，屏幕四周同步出现红色渐变外框脉冲，但中央操作区域保持透明；
- 用压力条显示已消耗时间；
- 保留樱色插线室的整体视觉语言，但降低非必要装饰。

## 5. 时间与错误规则

- 倒计时覆盖整局，不在每个线组完成后重置；
- 时间归零即挑战失败；
- 不设置生命值；
- 接错线不额外扣除时间；
- 接错后的具体回退反馈沿用基础解线规则，不增加新的惩罚层。

RUSH 的压力只来自“单位时间内完成全部线组”，避免规则过多导致玩家无法判断失败原因。

## 6. 开局提示

进入挑战前必须明确告知本局规则：

- 模式名称：`RUSH`；
- 本局倒计时；
- 当前固定线组的基本目标；
- 开始按钮。

玩家应在开始前知道自己面对的是速度挑战，不能在进入后才被动发现倒计时。

## 7. 结算与流转

### 成功

显示“挑战成功”，并提供：

- `下一关`：独立 RUSH 的第 1～9 关按顺序进入下一张卡；
- `下一轮随机挑战`：独立 RUSH 第 10 关完成后，或本局来自总随机池时，返回总挑战池；
- `回到主界面`。

### 失败

显示“挑战失败”，并提供：

- `重新开始`：重试当前 RUSH 线组；
- `回到主界面`。

失败后不自动更换题目，保证玩家可以针对刚才的固定挑战练习和改进。

## 8. 首期验收标准

- [x] 已完成 10 个固定 RUSH 线组的设计稿或数据定义；
- [x] 前两张热身卡为 20、22 条，以短线、少转角和较多开局出口降低首次门槛；
- [x] 第 3～10 张 RUSH 卡不少于对应随机挑战参考线数的 80%；
- [x] 后续卡的固定时限包含 3D 旋转观察预算；
- [x] 每个线组都有独立、明确的固定时间；
- [x] 每个线组经过可解性和空间安全验证；
- [x] RUSH 开局前显示规则和倒计时；
- [x] 主界面独立 RUSH 固定从第 1 关开始，并按顺序进入后续关卡；
- [x] 总随机挑战池中的 RUSH 仍随机抽取固定卡；
- [x] RUSH 只生成中央线组，不生成左右家电；
- [x] 倒计时覆盖整局，归零后进入失败结算；
- [x] 顶部倒计时每秒缩放一次，且越接近结束缩放越强；
- [x] 倒计时末段逐渐放大且峰值不超过 2 倍，放大后仍停留在屏幕顶部四分之一区域；
- [x] 最后 5 秒倒计时明显变红，屏幕四周同步显示不拦截操作的红色渐变警报；
- [x] 独立 RUSH 成功后进入下一关，完成第 10 关后可以进入总随机挑战或回主界面；
- [x] 失败后可以重试当前题或回主界面；
- [x] RUSH 可以作为独立入口，也可以作为总随机池中的一种规则。

## 9. 暂不在本阶段确定的内容

- 10 个线组的最终难度排序；
- 是否避免连续抽到同一组；
- 计分、最佳记录和排行榜；
- 是否在结算页展示用时、拆线数量等统计；
- 手机竖屏布局适配。
