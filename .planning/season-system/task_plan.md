# 任务计划：四季环境系统

## 目标
在完全保留当前春季白天与春季夜晚视觉的前提下，实现春、夏、秋、冬四季与昼夜正交组合、可平滑中断重定向的环境系统，并完成可见效果、季节选择器与回归验证。

## 当前阶段
阶段 12：按用户反馈返工粒子、配色与主界面层级

## 范围边界
- 本轮实现天空、云、雾、环境光、后期色调、开场粒子、游戏环境粒子和季节选择器。
- 不修改玩法、关卡、碰撞、评分、插线逻辑、家电固有颜色和音频。
- 不实现现实日期自动切季、随机天气、雨天、暴风雪、积雪或落叶堆积。
- 冰箱技能冰晶与冬季环境雪必须保持两个独立语义层。
- 保护工作区已有未提交修改，只对重叠文件做窄范围补丁。

## 季节视觉合同

| 季节 | 白天 | 夜晚 | 环境粒子 |
|------|------|------|----------|
| 春 | 当前效果原样保留 | 当前效果原样保留 | 粉色樱花瓣 |
| 夏 | 青蓝晴空、大型积云、暖阳 | 深钴蓝、少云、无发光点 | 少量嫩绿叶 |
| 秋 | 冷高空、暖地平线、低角度金光 | 烟熏靛蓝、暗暖云底 | 红黄秋叶、阵风翻滚 |
| 冬 | 冷蓝灰、分层阴云、淡雾 | 深冷海军蓝、稀疏星光 | 远近两层柔和纸片雪 |

## 过渡合同
- 默认季节切换时长约 2.4 秒；减弱动态约 0.25 秒。
- 连续属性使用平滑插值；云形和粒子类型使用双层交叉淡化。
- 切换中收到新目标时，从当前混合状态继续，不跳回上一个稳定状态。
- 昼夜切换沿用当前时长和交互；季节切换不改变昼夜目标。
- 春季配置必须直接复用当前常量，禁止“近似还原”。

## 验收标准
- [x] `season=spring` 的白天和夜晚与当前基准无可见回归。
- [x] 四季隐藏文字后仍能从背景、云和粒子在一秒内识别。
- [x] 季节切换无闪白、闪黑、粒子瞬间清空或云层跳变。
- [x] 季节与昼夜可同时过渡并正确到达组合目标。
- [x] 中央电线、插头和插座保持视觉主体，家电固有色不被全局染色。
- [x] 冬季环境雪不会触发或冒充冰箱技能状态。
- [x] 减弱动态与低画质模式有效，粒子系统不在每帧创建对象。
- [x] 构建和针对性测试通过。

## 已做决策
| 决策 | 理由 |
|------|------|
| 春季作为零改动基准 | 用户明确要求保留当前主题效果 |
| 季节与昼夜正交 | 能正确表达春夜→夏夜等组合，不产生亮度跳变 |
| 环境参数数据驱动 | 避免为八种组合复制整套逻辑 |
| 粒子交叉淡化而非几何变形 | 花瓣、叶片和雪花轮廓差异大，硬变形会显得廉价 |
| 每 60 秒自动轮换并保留手动快捷按钮 | 用户需要短周期自动演示，同时仍要快速测试四季 |
| 程序化资产和实例化渲染 | 延续当前 Three.js 纸感风格并控制性能 |
| 夏秋冬粒子回归二维面片 | 用户确认立体纸艺过于突兀；应以樱花的轻盈、圆润和尺度为统一基准 |

## 遇到的错误
| 错误 | 尝试次数 | 解决方案 |
|------|---------|---------|
| `sky.ts` 旧夜云颜色常量在季节环境接管后未使用 | 1 | 删除两个失效局部常量，季节环境成为云色唯一来源 |
| 桌面新增季节按钮后 `#game-actions` 左移并撞到 `#play-tools` | 1 | 桌面操作区改到全局工具栏下一行，移动端继续使用底部布局 |
| 软件 WebGL 首屏预热降帧导致 2.4 秒季节过渡被拉长，键盘事件双层处理导致焦点竞争 | 1 | 季节 wall-clock 步长上限调为 0.25 秒；按钮键盘事件停止冒泡并同步聚焦；浏览器测试先等待首屏预热完成 |
| 隐藏菜单的 `visibility` 参与 0.2 秒 transition，打开瞬间仍不可聚焦；测试把菜单项误当顶层工具按钮 | 1 | `visibility` 改为立即切换；工具栏样式断言只检查四个顶层按钮；WebGL 重测试改用 DOM click 与 120 秒预算 |
| 首屏 ready 后软件 WebGL 仍低至约 1 FPS，0.25 秒步长上限把季节过渡拉长到十余秒 | 1 | 允许单帧计入最多完整 2.4 秒 wall-clock；无可渲染帧的停顿不再延长季节时长 |
| 极低帧率下季节可在下一可渲染帧完成，测试无法保证同时采到两个 `transitioning=true` 的窄窗口 | 1 | 改验两个正交目标同时被接受，再分别验最终夏夜组合，不依赖中间采样帧 |
| 重定向后诊断发布前仍保留上一个夏季 `progress=1` 快照，单独轮询 progress 误判完成 | 1 | 完成条件同时绑定 `targetMode=autumn`、`mode=autumn` 与 progress，排除陈旧诊断 |
