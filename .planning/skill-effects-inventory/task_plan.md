# 技能模式效果整理与逐项修改清单

## 目标

把技能模式的 29 个家电技能按四个表现层完整列出：

1. 技能逻辑：触发条件、随机目标、状态/线缆/生命值变化、是否需要玩家选择。
2. 前端动画：技能提示阶段、3D 技能特效、全屏后处理、线缆和插头表现。
3. 图标：BUFF/DEBUFF 状态图标、图标计数、悬停/键盘提示。
4. 玩家提醒：技能触发提示、效果生效提示、结算提示、目标高亮、输入锁定和选择提示。

## 修改顺序

- [x] 读取技能规则、UI、3D 资产、后处理和游戏调度代码。
- [x] 建立 29 技能逐项效果矩阵。
- [x] 标出没有专属效果资产、资产存在但没有接线、逻辑与表现不一致的项目。
- [ ] 用户确认第一个要修改的技能。
- [x] 将 11 个状态图标和打印机 pending 改为生命值/提示同类的 CSS Low Poly 制作方式，并移除 GPT atlas。
- [ ] 每次只修改一个已确认技能，并补充对应测试/截图证据。

## 规则边界

- 本文是实现盘点，不替代 `.planning/appliance-skill-challenge/task_plan.md` 的已确认规则。
- 技能默认在正确连接家电后自动结算；玩家的主要决策是抽线顺序。
- 当前只有扭蛋机卡牌和智能垃圾桶回收保留一次明确选择流程。
- 持久状态最多同时占用一个 BUFF 槽和一个 DEBUFF 槽；一次性效果不占槽。
- 29 个注册技能、11 个状态图标和技能模式的三段式结算顺序以代码当前值为准。

## 关键实现入口

- `src/skill/SkillChallengeEngine.ts`：29 个技能注册、状态机、命令和结算规则。
- `src/game/Game.ts`：正确抽线事务、技能触发、目标高亮、线缆变更、输入锁和调度。
- `src/skill/SkillChallengeUi.ts`：状态槽、技能 cue、扭蛋卡、回收选择提示。
- `src/skill/SkillEffectModelKit.ts`：技能 3D 瞬时/持久资产和资产池。
- `src/style/post.ts`：蒸汽、咖啡、电视故障、打印扫描、泡泡五类全屏效果。
- `src/styles.css`：HUD 图标、提示框、卡牌翻转、回收提示和输入锁视觉。
- `tests/skill-challenge*.spec.ts`、`tests/skill-effect-assets.spec.ts`、`tests/skill-status-icons.spec.ts`：现有逻辑和表现验收。
