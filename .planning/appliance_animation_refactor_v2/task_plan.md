## 已做决策
| 决策 | 理由 |
|---|---|
| 新建独立 scoped 计划目录 | 工作区没有现存 `.planning` 活动计划，避免影响用户其他内容 |
| 游戏与图鉴只调用同一个表演模块 | 交接文件要求 replace, don't layer；调用端不保留动画实现 |
| 先做红色回归，再实施 | 必须证明测试能捕获“双动画叠加”本身 |
| 图鉴自动旋转保留在查看职责中 | 它不是通电动画，也不是重复特效来源 |

## 遇到的错误
| 错误 | 尝试次数 | 解决方案 |
|---|---:|---|
| 首次读取 UTF-8 中文交接文件出现乱码 | 1 | 改用 `[IO.File]::ReadAllLines(..., UTF8)` 分段完整读取 |
| Windows PowerShell 中两次正则引号转义失败 | 2 | 改为单引号简单模式和分组 `rg`，不再复用失败命令 |
| Windows 下 `rg src/path/*.ts` 不展开 glob | 1 | 改用 `rg -g '*.ts' src/path` |
| 补丁首次落到父级 Git 根目录 | 1 | 精确迁移本轮新建文件，并固定补丁路径使用 `arrow-cube/` 前缀 |

## 安全边界
- 不运行 `git reset --hard`、`git checkout --` 或任何批量清理。
- 只修改本任务所需动画、模型特效、测试和文档。
- 任何已修改文件先核对当前差异，保留用户现有改动。
- 所有任务文件均以 `arrow-cube` 为项目根目录。
