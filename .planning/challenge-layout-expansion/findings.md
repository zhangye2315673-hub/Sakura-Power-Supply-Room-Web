# 调查记录

## 2026-09-04 初始盘点

- 当前分支为 `codex/stage-snapshot-20260827`，工作区包含大量与家电技能、线路和挑战 UI 相关的既有未提交修改。
- 普通随机使用 `RANDOM_PUZZLE_TEMPLATES`，当前数据结构是一种规格对应一套模板。
- 技能模式优先读取 `SKILL_PUZZLE_TEMPLATES`，缺失规格回退普通随机模板。
- 探索模式目前复用普通随机生成路径，没有独立基础线路集合。
- 双头挑战当前只有 34、37、40 三种线数，每种一套母模板。
- 现有种子变换只提供旋转、镜像、轴交换和颜色重排；这些不能替代新的基础拓扑。

## 实现原则

- 将模板索引升级为模板数组，并让种子稳定选择基础拓扑槽位。
- 模板选定后继续使用现有空间变换、颜色重排、验证和回退逻辑。
- 探索模式用显式生成模式选择独立模板，不能再隐式伪装为普通随机。
- 生成文件必须由脚本产生，验证脚本直接遍历原始基础模板，避免只验证运行时变换后的少量样本。
- 双头模式从零生成一个40根候选超过2分钟，不能作为批量模板扩充路径。改用已验证母模板的局部内部拐弯段重排：端点不动、整组重新做几何和逐步端点验证，因此不会破坏真实视觉插头位置。
