# 阶段二：关卡节奏与辨识度

日期：2026-09-11

本阶段围绕“关卡节奏与辨识度”完成了 8 关战役的统一内容与布局调整。

## 已完成

- 为 8 个战役关卡增加名称、阶段标签和简短观察目标，并接入首页选关、游戏 HUD、目标卡、通关页和下一关预览。
- 使用固定的战役谜题布局，避免同一关因随机生成造成难度和观感波动；随机模式与技能模式仍使用原有生成器。
- 调整后 8 关的线缆数量为 `5 / 7 / 9 / 12 / 16 / 18 / 24 / 28`，初始可移除数量为 `3 / 3 / 3 / 4 / 4 / 5 / 6 / 6`。
- 为不同关卡配置不同家电组合和形状主题，让灯具、厨房、书桌、家务、音乐、游乐、厨房长线和全屋组合逐步展开。
- 保留原有核心旋转、倾斜、拔线、星级和解锁规则，以及现有深紫、樱红、奶油色描边 UI 体系。
- 目标卡支持折叠；开始关卡时显示，首次成功拔线后自动收起，玩家仍可手动展开。

## 验证

- `npm run build`：通过，TypeScript 检查与 Vite 生产构建均成功。
- `npm run verify:levels`：8/8 通过。包含精确数量、初始可移除范围、几何合法性、连通性、密度、无孤立线缆，以及逐步解法中每一步可操作性检查。
- `node scripts/check-campaign-ui-stage2.mjs`：桌面 1280×800、竖屏 390×844、横屏 844×390 均通过。该检查使用真实 UI 模块和 CSS，但关闭 WebGL，仅验证界面状态与布局。
- `git diff --check`：无空白错误；仅有 Git 的 LF/CRLF 提示。

## 限制

本阶段没有把完整 WebGL 游戏逐关自动玩完，因此关卡的最终“手感”和玩家是否喜欢，仍需要在正常浏览器中由人实际试玩判断。固定布局已经保证了重复进入同一关时的结构稳定，后续可以依据试玩反馈继续微调第 6–8 关的节奏。

## 后续微调：收紧结算信息

结算摘要改为只显示当前关卡和下一关（或战役完成提示），移除重复的总进度、解锁说明、累计耗时、累计错误和推荐重玩文案。用时、错误、星级和本关最佳记录仍保留。
