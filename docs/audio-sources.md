# Audio sources and licenses

The day/night and appliance sound system currently uses only procedural Web Audio synthesis.
No third-party recordings or samples are included.

The synthesis layer covers motor, air, water, heat, screen, paper, impact, bubble, and musical
textures with oscillators, deterministic filtered noise, and short amplitude envelopes. Future
sample replacements must be project-authored or CC0 and added to this file with the source URL,
author, license, and modified filename.

## Kenney audio integration (2026-09-08)

The first gameplay audio pass uses a small curated subset from the locally supplied
`E:\KenneyALLin1\Audio` collection. The selected Kenney audio packs include `License.txt`
files identifying the content as Creative Commons Zero (CC0). Files are copied into
`public/audio/kenney/` and used as browser-playable OGG assets:

- Interface Sounds: `confirmation_002.ogg`, `drop_002.ogg`, `error_004.ogg`, `pluck_002.ogg`, `click_001.ogg`
- Digital Audio: `zapTwoTone.ogg`, `powerUp7.ogg`
- Sci-Fi Sounds: `computerNoise_001.ogg`
- Music Loops: `Retro Mystic.ogg`, `Night at the Beach.ogg`

Source: https://kenney.nl/assets (Kenney audio collections, CC0 as documented in the supplied packs).
