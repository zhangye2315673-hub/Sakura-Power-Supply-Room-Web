# Audio sources and licenses

The day/night and appliance sound system currently uses only procedural Web Audio synthesis.
No third-party recordings or samples are included.

The synthesis layer covers motor, air, water, heat, screen, paper, impact, bubble, and musical
textures with oscillators, deterministic filtered noise, and short amplitude envelopes. Future
sample replacements must be project-authored or CC0 and added to this file with the source URL,
author, license, and modified filename.
