# Humidifier v2 image analysis

## Intake

The admitted source is the archived v1 front, side, back and three-quarter runtime capture. All four 1200x830 images passed the deterministic reference-admission gate. No Comfly or OpenAI credential was available in the environment, so this is explicitly a `conditional-fallback` intake and none of the images is represented as GPT Image 2 output.

## Object-space observations

The humidifier is a compact radial appliance with a low cream base, transparent upper reservoir, continuous tank seam, top rotary mist crown, front dial panel and rear service bank. The animation identity is larger than the idle object: eighteen mist pivots rise from the top socket, nine cloud lobes assemble above it, and thirty-six volumetric drops return toward the machine. +Y is up, +Z is front.

## V2 direction

The body uses a twelve-sided tapered profile with a pinched waist. The reservoir, crown and control panel are enlarged within the archived envelope to improve game readability. Solid parts receive 0.0048/0.0041/0.0033 stable ink with 0.18 object-space variation. Transparent water, mist, cloud light and rain are excluded from heavy ink.

## Frozen contract and limits

The archived bounds, negative hidden-effect ground, node parent paths, local transforms, socket directions and animation timeline are authoritative. Hidden atomizer hardware, wiring and ducts remain inferred and omitted. The v2 faceting is intentionally more graphic than the softer v1 screenshot.
