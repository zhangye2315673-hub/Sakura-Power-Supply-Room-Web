# Radio v2 image analysis

## Intake

The admitted source consists of front, side and back crops from the existing radio turn-sheet plus the existing three-quarter render. They are copied under `references/intake-v2/radio/views/` as conditional fallback evidence. No GPT Image 2 output was available in this environment, so these files are explicitly not generated concept art.

## Object-space observations

The radio is a wide shallow tabletop receiver: cream faceted shell, Sakura inset front fascia, left recessed speaker with 16 horizontal slats, upper-right frequency window and crosshair cursor, unequal lower controls, rear service panel with a 4x4 vent grid, four feet, and a three-section hinged telescopic antenna. +Y is up, +Z is front, and the floor remains y=0.

## v2 direction

The v2 build uses low-poly planar shoulders and shallow two-segment bevels, 2-3 Toon bands, cool violet shadow tint, and stable uneven ink. The geometry is deliberately more graphic and game-readable while preserving every existing runtime pivot, socket, node name, parent path, animation trajectory and package envelope.

## Unknowns and limits

Electronics, speaker chamber depth, battery compartment, underside fasteners, and antenna internals remain inferred. The frozen v1 runtime contract is authoritative for all hidden anchors and collision dimensions.
