# SAKURA Desktop Computer — 三视图分析

## 适用性与分类

- 技术检查：`front.png`、`side.png`、`back.png` 均可解码，尺寸约 557×941，入库检查均为 `ADMITTED`。
- 语义适用性：通过。三张图分别给出正面、侧面、背面，主体无遮挡，能约束显示器、支架、键盘、鼠标与塔式机箱的外部体积。
- 主体类型：桌面电脑套装（显示器 + 塔式主机 + 全尺寸键盘 + 鼠标），`primaryDomain=object`。
- 复杂度：`complex`。原因是五个独立宏观组件、三层支架与端口层级、键帽/散热孔的高密度重复系统、多材质分区和通电状态动画。
- 参考视角：近似正交产品三视图；垂直线平行，透视收敛很弱。前视图用于宽高和横向布局，侧视图用于深度，背视图用于支架与接口。

## 逐层观察

### 1. 整体轮廓与比例

- 总布局横向展开：显示器居左、主机居右；键盘位于显示器前下方，鼠标位于两者之间偏右。
- 显示器为宽屏圆角矩形，宽高约 1.65:1，厚度明显但很薄；屏幕黑色面板由奶油色宽边框包围。
- 主机为竖直圆角长方体，高略高于显示器屏幕本体，宽约显示器的 0.36；侧面深度约为宽度的 1.2。
- 键盘宽约显示器的 0.86，前后深度约宽度的 0.24，外壳前缘圆角并带轻微斜坡。
- 鼠标为低矮拱形、前窄后宽的连续曲面；侧视图显示奶油色下壳和粉色上壳分层。

### 2. 宏观—中观—微观组件

- 宏观：显示器总成、显示器支架、主机总成、键盘总成、鼠标总成。
- 显示器中观：奶油背壳、粉色/奶油边框、深灰屏幕、背部方形安装座、立柱、两级底座。
- 主机中观：奶油主壳、粉色顶盖、前置粉色 I/O 条、侧盖接缝、后置粉色 I/O/通风面板、四个脚垫。
- 键盘中观：奶油底壳、粉色内托、白/粉键帽矩阵、长空格键、右侧大键组。
- 鼠标中观：奶油底壳、粉色拱形上壳、中央缝、滚轮和指示缝线。
- 微观：主机花形徽标、电源键、圆形状态点、双 USB 口、后置双散热孔阵列、后置接口列、IEC 电源插口、显示器花形徽标、显示器底边状态点、键帽间隙、鼠标滚轮槽。

### 4. 材质与颜色（PBR 观察）

- 奶油塑料：暖白/浅米色，高值、低饱和；介电质，`metalness=0`，参考为缎面塑料，粗糙度约 0.55–0.7，边缘有真实倒角高光。
- SAKURA 粉塑料/烤漆：低饱和浅粉，中高值；介电质，粗糙度约 0.38–0.55，略低于奶油壳；用于支架、主机顶盖、I/O 条和按键分区。
- 屏幕玻璃：深灰近黑，低粗糙度，通电前无透射；应使用独立发光层而非把亮度烘焙进壳体。
- 端口/散热孔：深灰内腔，粗糙度较高；插口触点/边框可用低粗糙度金属点缀，但参考没有暴露大量裸金属。
- 橡胶脚：暗粉棕/灰粉，高粗糙度。

## 不确定与推测区域

- 主机内部主板、显卡、CPU 散热器、电源和风道完全不可见，省略，归类为 `inferred`。
- 参考没有显示真实风扇叶片，只显示散热孔；动画中的背后风扇旋转属于用途驱动的合理推测。
- 显示器铰链内部、旋转轴承和前后倾止挡不可见，pivot 位置按安装座与立柱连接关系推测。
- 键帽下的轴体、PCB 和键盘背面防滑脚不可见；键帽按标准行列近似分配。
- 鼠标光学传感器、左右键内部微动和底部滑脚不可见。
- 电源线、显示信号线和键鼠连接线未在参考出现，只提供 socket，不渲染线材。
- 后置端口类型只按可见形状重建，不声称对应精确主板 I/O 规范或品牌布局。

## 质量合同摘要

- 必须从正、侧、背、三分之四视角保持五件套外轮廓和相对比例。
- 显示器/支架/主机/键盘/鼠标必须为独立命名组件；键帽、散热孔和端口为重复/微结构系统。
- 通电 5.2 秒内需清晰经历：主机电源键/状态灯亮起 → 屏幕启动光 → 桌面窗口出现 → 光标移动/窗口变化 → 键盘按键反馈与风扇状态；`stop()` 精确恢复黑屏、无灯、无按键位移。
- 继续门禁：所有关键系统得分不少于 0.70；任何宏观比例错误、浮空支架、屏幕用途不清、背面散热/接口缺失、停止后状态残留都必须返工。
- 性能预算：目标不超过 110 draw calls、80k triangles；高密度散热孔与键帽必须复用几何，避免每帧分配。
