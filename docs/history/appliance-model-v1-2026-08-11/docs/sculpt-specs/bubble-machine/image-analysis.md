# 泡泡机图片分析

- 准入：原图是同一对象的前、侧、后三视图拼版，整版被算法判为 fragmented；拆出的三个单对象裁切均通过准入。技术探测为 1672×941 PNG，无尺寸或解码警告。
- 类型：便携式电动泡泡机，`primaryDomain=object`，几何硬表面、分层塑料壳、径向重复机构与透明效果混合；复杂度判定为 `complex`。
- 整体轮廓：正/后视为高宽比约 1.12 的圆角方箱，深度约正面宽度 0.72；机壳底部四脚；侧液罐造成右后方不对称凸出。
- 宏观组件：圆角主机壳、前工作窗/轮盘总成、侧挂液罐、后风扇格栅、底脚。
- 中观组件：前粉色厚边框、烟灰透明窗、八环轮盘和中心轮毂、接液托盘、顶部控制、液罐盖、侧通风孔、后风扇叶与同心格栅、四角螺钉、电源接口。
- 微观细节：壳体倒角和分件线、轮环细波纹、轮毂同心帽、格栅辐条、控制旋钮指示线、虹彩泡泡边缘。
- 材料：机壳为高价值米白注塑塑料（非金属、缎光）；粉色件为低粗糙度透明涂层塑料；前窗为烟灰透明塑料；液罐为半透明粉色塑料；风扇腔为深灰；螺钉/接口为深灰硬件；泡泡膜为薄透明虹彩效果。
- 关键身份特征：八个泡泡环的径向轮盘、正面烟灰窗口、右侧粉色液罐、背部大同心圆风扇格栅、米白/樱粉 SAKURA 配色。
- 连接关系：轮盘围绕前轴 pivot；每个泡泡环通过独立辐条连接中心轮毂；侧液罐通过后侧挂架/液路 socket 与机壳重叠；后风扇围绕后轴 pivot；脚垫与底壳面接触。
- 明确推测：内部电机、齿轮、泵、液路、风扇轴承不可见；电源接口位置未展示；侧液罐挂架背面形状与底面螺钉不可见；其实现仅提供合理 socket/外壳，不虚构内部机械细节。
