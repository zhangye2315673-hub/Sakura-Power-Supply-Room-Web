# SAKURA 爆米花机图像分析

## 准入与分类

- 主体：台式爆米花机，`primaryDomain=object`，置信度 0.99。
- 参考图是一张三视图图板：正视、右侧视、后视。整图因三个主体不连通被自动准入脚本判为 fragmented；从图板裁出的三张单视图全部通过准入，且不是重复视角。
- 结构复杂度：`complex`。原因是透明仓体、顶置爆谷组件、颗粒重复系统、出货通道、独立控制件和动画层级同时存在。

## 整体形体与比例

- 总体为高约宽 1.55 倍的圆角竖直机柜，深度约为正面宽度 0.72。
- 下半部是不透明奶油色圆角机箱；上半部是四面透明仓，外围有浅色立柱和上下压框。
- 顶部是宽大的粉色低拱顶，中心有短圆角冠钮；底部粉色窄裙边与四个脚垫形成稳定落地轮廓。
- 正面出货拱口与外伸托盘形成最显著负空间；后面散热槽阵列形成背面身份特征。

## 组件层级

- 宏观：下机箱、透明仓总成、顶盖总成、出货总成。
- 中观：四根立柱、上下仓框、顶置爆谷/搅拌组件、控制按钮、后散热板、侧面释放结构、脚垫。
- 微观：爆米花颗粒堆、颗粒瓣形、接缝、边缘倒角、暖光、散热槽阵列。

## 空间关系

- 透明仓嵌入下机箱上表面与顶盖下框之间，四根立柱在四角重叠连接上下框。
- 顶置爆谷组件嵌在顶盖下方中央，动画转轴位于其竖直中心线。
- 出货拱口凹入下机箱正面；托盘从拱口下缘向前伸出并与机箱保持重叠。
- 后散热槽贴在后壳中下部；侧面圆按钮位于仓体下方侧柱区域。

## 材质与颜色

- 奶油白注塑外壳：介电、缎面、低金属度，真实圆角承接高光。
- 樱花粉注塑件：拱顶、按钮、底边、托盘与脚垫，较低粗糙度并带 toon 高光分层。
- 透明仓：浅暖透明塑料/玻璃感，低雾度、低不透明度；轮廓和立柱必须保持可读。
- 爆米花：暖黄白哑光颗粒，瓣状不规则轮廓与少量金黄阴影核。
- 腔体/散热槽：暗玫棕色哑光材质，用于深度和 AO 读数。
- 通电状态：顶置机构下方出现暖黄发光，映亮颗粒但不改变整体 SAKURA 配色。

## 身份细节与不确定性

- 身份细节：粉色低拱顶、透明四面仓、可见爆米花堆、顶置圆盘机构、正面拱形出货口与托盘、右下圆按钮、背部十条竖向散热槽。
- 推测：不可见加热盘、电机、传动、底面结构、电源线与实际内部出货阀门；这些只以动画锚点/插线 socket 或暗腔体表达，不宣称准确复原。
