# SAKURA 插头与线缆家族图像分析

## 适用性结论

- 正式造型参考：`reference-v1-round-two-pin.png`，570 x 1290，接纳门通过。
- 七款样式板与固定种子游戏截图只作为家族关系、比例和使用情境证据；它们因多对象分散而不作为单体轮廓真值。
- 目标是程序化重设计，不是制造级复刻。当前参考足以锁定外包络、连接次序和 SAKURA 风格，但背面细节、内部导体和真实材料微结构不在重建范围内。

## 1. 识别与分类

- 对象：实时浏览器解谜游戏中的彩色电源/数据插头与电缆家族。
- 主域：`object`。
- 形态语言：低多边形硬表面主体 + 纤维/线束型电缆。
- 结构：共同壳体家族，前端有七种可替换终端组件；后端通过护线套连接线身。
- 运动需求：整件移动、沿原折线路径逐段抽离、双头反向抽离、飞向家电接口、悬停与阻挡状态反馈。

## 2. 总体形体与轮廓

- 当前主体是轴对称短圆柱体，前后各有轻微收肩，最大半径 0.18，根部到终端最大长度 0.64。
- 参考中主壳高度约为最大直径的 1.05–1.15 倍，后端护线套约占总可见壳体长度的四分之一。
- 当前 20 边圆柱在平面 Toon 光下形成宽竖向色带；v2 保留这种几何可读性，但改成 12 边旋转轮廓和更清晰的前肩、后颈与面圈。
- 线缆保持圆形截面和原正交中心线；视觉圆角必须位于原折线两条腿形成的局部包围范围内，不得自由样条越界。

## 3. 宏观—中观—微观分解

- 宏观：插头总成、线身、单头尾帽/第二插头。
- 中观：护线套、后颈、主壳、前肩、接口面圈、终端总成、状态指示灯。
- 微观：护线套浅环槽、壳体前后倒角、接口孔/针脚、内嵌指示灯、线缆 90° 相切圆角、墨线轮廓。

## 4. 空间关系与连接

- `<线身, 嵌入, 护线套后端>`：轴向重叠，禁止可见缝隙。
- `<护线套, 嵌入, 后颈>`：同轴连接，护线套半径从 0.105 过渡到约 0.14。
- `<后颈, 支撑, 主壳>`：连续旋转轮廓，不允许浮空环件。
- `<前肩, 承载, 接口面圈>`：同轴表面接触，面圈必须位于主体安全包络内。
- `<终端总成, 嵌入, 接口面圈>`：每种终端保留当前数量、相对位置与朝向。
- `<状态灯, 嵌入, 主壳侧面>`：由凸起球点改为浅内嵌圆点，仍可被悬停/通电状态驱动。

## 5. 材料与表面

- 外壳：有色模压塑料的 Toon 表达，非金属；三段明暗，冷紫阴影，不使用照片投影或写实纹理。
- 护线套与线身：同色但更深一档的橡胶/柔性塑料表达；两到三段 Toon 明暗，靠色值和截面区分，不靠噪声纹理。
- 针脚/金属外壳：冷灰紫低饱和金属色，两到三段 Toon 明暗；不引入高光闪烁或镜面 PBR。
- 接口暗腔：深紫灰，两段 Toon 明暗，必须是真实凹口/前置暗面而不是壳体上的贴图。
- 轮廓：主壳、面圈和线身使用深紫色倒置壳墨线；微小针脚不重复加粗，避免线团感。

## 6. 颜色与完成度

- 继续使用项目现有红、黄、青、蓝、橙、紫、绿和樱粉色板。
- 饱和色只承担主壳与线身，前肩/护线套通过同色降亮度建立层级。
- 整体必须保持 Sakura Crossing 的窄色板、平面色块、冷紫阴影和克制细节，不做软胶玩具、拟人脸或赛博机械零件。

## 7. 身份特征

- 七种前端：圆形双针、Type-C、扁平双片、三针、圆形接地、DC 圆孔、磁吸触点。
- 统一家族结构：共同的后端护线套—后颈—主壳—前肩—面圈比例。
- 可见状态点：保留交互反馈功能，但视觉上改为内嵌。
- 线缆折点：v2 的关键身份变化是严格相切、低多边形、固定半径的 90° 圆角，而不是现有球形鼓包。

## 8. 不确定性与限制

- 参考没有单独展示七款的背面和侧面；未见区域按轴对称共同壳体处理，置信度 0.8。
- 七种终端的真实工业尺寸不是目标；只保留当前游戏识别和包络，置信度 1.0。
- 线缆物理弯曲不会改变谜题中心线或碰撞体；v2 只改变渲染曲线，置信度 1.0。
- 这是风格化低多边形实时模型，不声明真实材料或制造尺寸精度。

## 质量契约

- 七款必须在固定正面、四分之三面和侧面都能凭终端一眼区分。
- 所有可见几何必须位于半径 0.18、长度 0.64 的既有安全包络内。
- 共同壳体至少包含护线套、后颈、主壳、前肩和面圈五个连续结构层；相邻部件必须有轴向重叠。
- 每个 90° 转角使用半径 0.13、受相邻短边 28% 限制的相切圆角；小于 0.025 时退回直角，禁止 Catmull-Rom 过冲。
- 线身保持 0.105 半径和 8 边截面；端点、点击逻辑、抽离距离及碰撞数据不变。
- 关键失败：接口辨识下降、包络越界、线头悬空、折角鼓包/打结、微小部件墨线过密、出现玩具或赛博机械语汇。
