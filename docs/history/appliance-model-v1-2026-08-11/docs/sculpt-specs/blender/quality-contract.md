# Blender quality contract

## 必须满足

- 杯体、杯盖、刀片、底座为独立命名 pivot/socket；游戏与图鉴共享 `AppliancePerformanceSystem` 的同一时间轴。
- 底座横摆幅度小于杯体；杯体有相位滞后、倾斜和 secondary motion，停止后精确回到建模基线。
- 杯内至少四类可识别的立体水果，带第二识别层/材质层；初始完整，随后逐步缩小、切碎、消失，不穿透明杯壁。
- 樱花粉半透明果汁由底部连续升高到接近杯口，液面和旋涡具有独立体积与旋转。
- 杯盖完成左右晃、两次竖直弹跳、回落杯口；高潮约 3.45 秒。
- 飞溅只从杯口 socket 发射，至少三种体积几何（圆润滴、拉长滴、厚冠/扁平 splash），并具有确定性的大小、旋转、距离和抛物线差异。
- 飞溅落地后短暂停留、压扁、淡出；不得使用 Plane、Sprite、Line 或穿出机身的旧黄色/蓝色面片。
- 不能修改 stand-mixer 行为。

## 运行时验收

- 0.0s：完整水果可见、果汁隐藏、所有 pivot 在基线。
- 1.2s：刀片高速旋转，水果仍可识别但开始切碎，果汁从杯底出现。
- 2.4s：水果显著缩小，粉色果汁超过半杯，杯体振幅明显高于底座。
- 3.45s：盖子抬起/弹跳，果汁接近满杯，多形态飞溅从杯口出现，且无杯壁/机身穿出。
- 4.5s：盖子回到杯口，液体高潮衰减。
- 断电/周期结束：对象 transform、visibility、材质透明度精确复位，飞溅池清空。

## 视觉风险与处理

- 透明杯容易产生绘制顺序问题：果汁 renderOrder 低于杯壁，杯壁 `depthWrite=false`，水果保持不透明并限制半径。
- 高位杯体摆动容易把盖子与杯口错开：盖子作为 jarPivot 子节点，局部弹跳，不独立漂移。
- 统一球形液滴会退化为廉价粒子：使用不同几何池与非均匀 scale，厚冠 splash 采用 Extrude/Lathe/Tube 体积。
