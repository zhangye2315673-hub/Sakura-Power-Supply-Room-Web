# 洗衣机程序化重建记录

## 参考与适用性

- 参考图：`D:/下载文件/ChatGPT Image 2026年8月2日 19_55_19 (8).png`
- 类型：复古家用前置滚筒洗衣机，参考包含近似正交的正、侧、后三视。
- 适用性：通过。三视能够锁定宏观比例、箱体深度、门圈层级和背部服务组件；灰玻璃后的内筒结构、铰链内部与底部仍不可见。
- 质量目标：实时浏览器用 Sakura toon 程序化模型。先保证轮廓、门圈、控制带与侧面深度，微小结构维持低面数。

## 比例锁定

- 总体 `2.70 × 2.99 × 2.02`，正面近方形，深度约为宽度的 `0.75`。
- 上部控制带约占总高 `16%`，依次为洗涤剂抽屉、主旋钮、显示区和三按钮。
- 门圈外径约占机身宽度 `65%`，门中心略低于正面中线；门圈和把手向前突出，避免平贴纸片感。
- 主体坐标：`+Y` 向上、`+Z` 为正面、地面 `Y=0`。

## Detail inventory 落地

1. 圆角主箱体、浅色正面板和强调色顶盖独立建模。
2. 控制带分为抽屉、抽屉拉槽、旋钮外环、旋钮体、指示线、显示屏和三按钮。
3. 门体包含强调色外门圈、深色胶圈、灰透明凸玻璃和右侧厚把手。
4. 内筒转子包含后盘、12个低成本孔点和5块彩色衣物体。
5. 两侧检修压槽、后部外压槽、内层压槽、下检修盖与6个固定件均为独立部件。
6. 排水软管、电源线、入口、悬挂插头与四个脚垫分件。

## 层级、pivot 与 socket

- `washer-door-hinge`：右侧门铰链 pivot，可围绕 Y 轴开启。
- `washer-door-assembly`：门圈、胶圈、玻璃和把手的共同父级。
- `washer-drum-rotor`：内筒与衣物的 Z 轴旋转 pivot。
- `washer-program-dial-pivot`：通电时旋钮转到工作档。
- `washer-detergent-drawer-pivot`：沿 Z 轴的抽屉移动层级。
- sockets：门铰链、门把、滚筒轴、抽屉、排水管、电源线。
- 所有主要网格均通过 `ApplianceModelKit` 注册到 `sculptRuntime.nodes`，可点击与分件定义一致。

## 通电动画

- 目标转速通过阻尼插值，不会在启动/停机时瞬间跳变。
- 内筒持续旋转；彩色衣物跟随滚筒位置，同时做独立反向翻滚和轻微前后位移。
- 显示屏、状态灯点亮，程序旋钮转到工作档。
- 内部模型根节点产生非常克制的高频横向/垂直振动，不改变外层拖拽坐标。
- `stop()` 关闭发光与震动并停止角速度，保留当时滚筒角度，避免突兀跳帧。

- 近方形圆角箱体与参考图的宽高、侧深比例。
- 上部三段式控制带、左抽屉、中旋钮、右显示和三按钮。
- 大型分层门圈、灰透明窗、右侧厚把手。
- 侧面大压槽、后部阶梯压槽、检修盖、固定件、软管和电源组件。

## 合理推测

- 滚筒深度、孔阵、衣物数量和内筒挡板被灰玻璃遮挡，当前为性能友好的视觉推测。
- 参考只展示一个侧面，模型为保持自由旋转可读性在两侧都放置了浅压槽。
- 门铰链内部、锁舌行程、软管在机身内的走向、电源线真实长度与底部调平结构不可见。
- 背面接口深度与悬挂插头结构按参考可见轮廓简化，不作为工程级家电结构复刻。

## 视觉检查重点

- 正面：门圈不能小，控制带不能厚成独立箱体，门把必须在右侧清晰可见。
- 三分之四：必须看出真实箱体深度、前门突出与侧面压槽。
- 背面：软管、电源线和阶梯后盖不能融成单一平板。
- Powered：滚筒/衣物的运动应比机身震动明显，显示亮度不可盖住 Sakura 赛璐璐层级。
