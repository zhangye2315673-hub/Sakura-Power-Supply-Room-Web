# 电热水壶程序化重建

## 质量契约与结构清单

这件模型按参考图三视图重建为浏览器实时用的 Sakura 赛璐璐家电。第一识别层是“上窄下宽的圆润壶身 + 左侧短壶嘴 + 右侧大 D 形把手负空间”，而不是依靠颜色或文字图标。组件分成壶身、肩带、底轨、电源底座、盖子、壶嘴、把手、水位窗、开关、后接口和脚，不合并成单一网格。

关键细节清单：

- 连续旋转体壶身，上肩收窄、下腹更宽。
- 独立奶油色壶盖、顶按键和环形盖缝。
- 低饱和金属短壶嘴、深色出口圈和蒸汽 socket。
- 双层 D 形把手，外层线路色软胶、内层奶油色握持面，保留明确负空间。
- 前方半透明纵向水位窗、独立水体和七条实体刻度。
- 前方电源开关、状态灯、独立圆形电源底座与后方接口。
- 四只低矮脚；精确底面螺丝因参考不可见而没有伪造。

## 动画层级

- `kettle-lid-hinge-pivot`：盖子拥有正确的后侧开合轴和 socket，当前通电演示不自动掀盖。
- `kettle-power-switch-pivot`：通电时按键压下并有一次轻微回弹。
- `kettle-body-pivot`：沸腾阶段只有非常小的高频震动，避免玩具式大幅摇晃。
- 水位窗中的九个气泡沿真实窗体范围上升。
- 九个蒸汽粒子以 `kettle-spout-steam-socket` 为起点，少量、低透明度、无 Bloom。
- `stop()` 会归零壶身、开关、水体与所有粒子，支持 5.2 秒后停机并再次启动。

## 还原与推测边界

准确还原的可见区域包括：主体锥度、壶盖层级、短壶嘴方向、右侧把手轮廓及负空间、水位窗、下部开关和底座。内部加热盘、温控器、线缆、隔热层、盖子密封圈、把手内部螺丝和底面紧固件被遮挡，属于推测或明确省略。该子代理运行时本地 `D:` 参考路径不可访问，因此可见比例基于任务中嵌入的清晰三视图，不能声称像素级测量已完成；最终浏览器图鉴需要再做正面、四分之三和背面轨道复核。
