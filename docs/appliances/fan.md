## 组件层级与动作轴

```text
appliance-model-fan
├─ fan-base-shell
├─ fan-base-accent-rail
├─ fan-speed-dial-pivot
├─ fan-oscillation-pivot             水平摆头轴
│  ├─ fan-support-column
│  └─ fan-head-hinge                 机头俯仰轴
│     ├─ fan-motor-housing
│     ├─ fan-rear-guard
│     ├─ fan-rotor-pivot             仅五叶转子旋转
│     └─ fan-front-guard
```

- `fan-head-socket` 位于俯仰轴中心。
- `fan-rotor-axis-socket` 位于扇叶轮毂中心。
- 前后护网不属于转子层级，因此不会随扇叶旋转。
- 所有网圈、网筋、电机、旋钮和扇叶都是命名组件，便于拾取和后续拆解。

## 几何与材质策略

- 底座和立柱使用带实际倒角的二维轮廓挤出，不用普通方盒代替梯形轮廓。
- 扇叶使用三次贝塞尔曲线封闭轮廓后浅挤出，形成可从斜侧面读出的厚度。
- 护网使用低分段 Torus 与六边圆柱，兼顾正面识别度和浏览器性能。
- 机身继续使用项目的三阶 toon 材质和冷紫阴影；配色由传入的线路强调色决定，不复制参考图粉色。
- 指示灯复用 `ApplianceModelKit` 的统一发光状态逻辑。

## 通电动画

- 扇叶：外部 `power` 驱动目标角速度，运行时约 `14.5 rad/s`；结束前会跟随外部 power 衰减，而不是独立永久旋转。
- 摆头：`fan-oscillation-pivot` 围绕 Y 轴小幅往复，振幅约 `±0.18 rad`。
- 俯仰：保留固定轻微下俯，并加入很克制的运行振动，避免护网与底座一起僵硬移动。
- 旋钮：通电时略微转向运行档，停机回零。

## 还原准确区域

- 圆形机头、梯形底座和细立柱之间的主比例关系。
- 前后双层护网、三层同心环、八根径向筋。
- 五片宽而后掠的扇叶轮廓及其独立转子层级。
- 后电机筒的锥度、背部端盖和水平通风槽。
- 俯仰关节、圆形侧盖、前旋钮、底部强调色包边。

## 合理推测区域

- 参考图没有展示护网卡扣内部结构；模型用浅叠合圈表达装配关系，没有虚构复杂锁扣。
- 电机轴承、电机内部与振荡齿轮不可见；只建立运行需要的 pivot 和 socket。
- 底座底面、电源线出口没有可靠证据，保持封闭简化。
- 扇叶精确弧高和背面加强筋无法由产品图定量恢复；按正面与侧面轮廓推测为浅挤出的弧形叶片。

## 当前限制

模型是 Sakura 风格的实时程序化重建，不是制造级 CAD。参考图本身带有插画化描边和非物理高光，因此材质以项目既有 toon 语言为准，没有尝试从图像反演写实 PBR 参数。

## 浏览器视觉校对

- 正面渲染：`artifacts/img2threejs/fan/render-front.png`
- 四分之三渲染：`artifacts/img2threejs/fan/render-three-quarter.png`
- 参考并排图：`comparison-front.png`、`comparison-three-quarter.png`

第一轮渲染发现机头中心过低，护网下沿与底座上沿重叠，导致立柱几乎消失。第二轮将：

- 支撑柱的局部高度从 `0.48` 调整为 `0.70`；
- 俯仰轴局部 Y 从 `0.51` 调整为 `0.78`；

调整后，正面轮廓恢复为“圆形机头—短立柱—梯形底座”三个层级，四分之三视角也能读出前后护网和后电机筒，不再像圆盘直接压在底座上。

当前仍存在的差异：护网管径为了小游戏远景可读性，比参考图略粗；扇叶弧面是浅挤出近似，没有恢复真实注塑叶片的连续翼型；电机内部与摆头齿轮没有图片证据，因此没有虚构。

基础 spec 校验通过。严格质量门禁仍要求完整 `componentTree`、参考 PBR 提取和逐 pass 的 AI 评分；本项目采用既有 Sakura toon 材质且当前子任务只交付模型模块，因此没有把严格门禁误报为通过。
