# 插头线三维关卡设计

## 核心原则

- 线团本身是关卡主体。外轮廓只限制大致范围，不要求线路为了描边而拉远、抬高或留空。
- 所有线路共享 `0.58` 的占格间距。不同关卡通过占格数量和占格范围变化，不通过压缩线距制造密度。
- 每条线只能沿三维正交网格行走，转弯均为 90 度。圆柱、球体等曲面造型呈现阶梯状，类似积木或体素模型。
- 线团必须形成一个相邻、饱满的整体。新增线路需要贴近已有线团，不能成为远离主体的孤线。
- 禁止跨线穿模、共用线道、自相交、插头碰线、插头撞自身以及同一条线头尾相撞。
- 主线关卡使用固定种子，重置必须复现完全相同的布局；随机挑战使用独立种子。
- 难度来自线路数量、依赖关系、空间占格和观察角度，不通过缩小点击区域或遮挡交互制造。

## 五关引导曲线

| 关卡 | 体素造型 | 线路数 | 最小占格跨度 | 设计目标 |
|---|---|---:|---:|---|
| 01 | 小正方体 | 5 | 4 x 4 x 4 | 少线但紧密盘绕，形成明确的小体块 |
| 02 | 长方体 | 7 | 5 x 3 x 3 | 横向扩展，保持连续线团 |
| 03 | 阶梯四棱锥 | 9 | 4 x 5 x 4 | 引入收拢层次和更多依赖 |
| 04 | 阶梯圆柱 | 12 | 4 x 5 x 4 | 用正交线路构成圆润的阶梯体积 |
| 05 | 阶梯球体 | 16 | 6 x 6 x 6 | 形成主线中最大、最饱满的三维线团 |

第五关完成后进入随机复杂模式。随机关卡使用 18 至 22 条线，从正方体、长方体、圆柱和球体中选择紧密的实体体素范围。四棱锥由固定第 3 关呈现；随机池不使用天然空心的圆环、拱门，也不使用收紧后容量不稳定的八面体和四棱锥，优先保证每个随机种子都能生成饱满线团。

## 生成约束

- 网格为 `11 x 11 x 11`，世界线距固定为 `LANE_PITCH = 0.58`。
- 候选线路优先在现有占格附近盘绕；第一条之后的每条线路都必须与已有线团相邻。
- 关卡以最小三轴跨度控制“由小到大”，以目标线路数控制“由少到多”。
- `minNeighborRatio` 控制占格相邻比例；所有关卡要求单一连通块且不允许孤立线路。
- 短线比例控制在 20% 以下，中线和长线承担主要盘绕与阻挡。
- 生成采用反向插入：每条新线插入时必须可拔，反转插入顺序即可得到保底解。
- 固定关卡不接受少生成线路的降级结果，线路数必须与目标值完全一致。

## 几何验收

`geometryValidation.ts` 对每组线路执行实体级检查：

- 不同线路的管体不能相交或共享同一线道。
- 单条线路的非相邻线段不能自相交。
- 插头实体不能碰到其他线路或自身管体。
- 同一条线的插头与尾端必须保留安全间距。

`gridOccupancy.ts` 对整体占格关系执行结构检查：

- 所有占用节点属于同一个连通块。
- 每条线路至少有一个占格与其他线路相邻。
- 相邻占格比例达到该关卡阈值。
- 三轴跨度达到关卡目标且不超出大致体素范围。

## 加载与切关

- 游戏运行时后台预生成下一关，通关后点击“下一关”立即收起结算面板并切换预取结果。
- 重置直接复用当前谜题，不重新执行生成器。
- 首屏关键样式内联，应用完成初始化后再显示，刷新时不暴露无样式 HTML。

## 验收命令

- `npm run verify:levels`：验证五个固定关卡的精确线路数、可解性、开局自由数、占格紧密度、连通性和几何安全。
- `npm run verify:random-levels`：抽样验证随机复杂关卡的数量、连通性、紧密度和几何安全。
- `npm run build`：验证 TypeScript 和生产构建。
- Playwright：逐关检查由小到大、由少到多的视觉关系，以及刷新、切关、桌面和手机布局。
