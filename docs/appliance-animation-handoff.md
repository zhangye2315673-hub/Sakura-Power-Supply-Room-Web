# 家电夸张动画续作交接

更新时间：2026-08-05

## 用户最终确认方向

目标不是让家电只抖动或开关，而是让玩家每拔出一根线都会想看家电接下来如何表演。每台家电需要有清晰的功能动作、高潮、屏幕级特效和可复位的完整周期。

1. 台灯：灯罩像有生命一样依次看向上下左右；每个方向短暂停顿后快速看向下一处。灯罩带动真实光源与可见手电筒式光束在屏幕前扫过。
2. 风扇：启动后在前方生成樱花，并以定向气流把新旧樱花吹过中间线组直至屏幕外。
3. 加湿器：雾气更高、更宽；顶部聚成小乌云，闪小闪电，随后从云底快速降雨回落到加湿器。
8. 洗衣机：大量泡泡像从门内挤出；滚筒越来越快，整机侧倾、短暂停住，再回正落地。
10. 咖啡机：水箱移到可见侧面；蒸汽更大、更宽；奶泡像啤酒泡一样越过杯沿并向外溢出。
11. 电热水壶：跳动明显；蒸汽更大更高；盖子左右来回跳；提示灯变红；整壶像急着关火一样强烈震动。
12. 电饭煲：增加深灰内锅和白米饭；米粒比爆米花更小更细；蒸汽增强；按钮明显下压和上提；大量米粒飞起后落回锅内。
13. 手机：左右快速晃动，并出现漫画式弯曲震动线。
14. 扫地机器人：激光雷达高速旋转；机器人离开原位绕小圆；周围碎屑被吸到底部；最后回到原位。
16. 扭蛋机：扭蛋轻弹出、落地弹两次；随后两半外壳砰地向左右打开，露出中间道具。
17. 爆米花机：内部跳动更剧烈；高潮期大量爆米花持续从出口喷出并朝屏幕前飞。
19. 智能垃圾桶：开盖后垃圾从屏幕外多个方向按抛物线飞入；最后一个垃圾先砸盖沿再掉入桶内，最后关盖。
20. 唱片机：空中出现大量明显音符，不只有纹波；盖板运动不得穿进内部圆盘。
22. 打印机：连续快速吐出多张纸；纸张向画面中间弹射，像过山车一样转圈后落地，而不是刚出现就消失。
23. 电磁炉：沸腾范围更大、更剧烈。
25. 除湿机：更多水滴与雾气从更大范围吸入；吸饱后腰部横向膨胀，形成滑稽的肥圆造型。
26. 便携音箱：周围有更大更明显的音符；机身随音乐膨胀和压缩。
27. 吹风机：风力更强；波纹中增加细长彩条，随气流高速摆动并在高潮时吹出屏幕。
28. 台式电脑：在机箱侧面增加可见风扇；键盘敲击加快；鼠标移动范围增大但不得穿模键盘或主机；机箱顶部高负载冒烟；屏幕快速切换多个界面，最后出现经典蓝屏。

未再次点名的家电继续沿用上一轮已经确认的逐台动画方案。

## 当前实现状态

上述 18 项都已经存在代码实现，分为两层：

- 模型内动画：各 `src/appliances/models/*.ts` 的 `animation.update/stop` 负责灯罩、滚筒、盖子、转盘、按键、鼠标、机身形变等局部和整机动作。
- 屏幕级表演：`src/systems/ApplianceSpectacleSystem.ts` 负责跨越模型局部边界的光束、樱花、云雨、蒸汽、泡泡、音符、纸张、垃圾、米粒、彩条和烟雾。

已确认的关键实现包括：

- 台灯四向注视停顿 + 可见光束和聚光灯同步。
- 风扇自产樱花 + 对背景 `PetalField` 施加定向风场。
- 加湿器高雾、云团、双闪电与快速降雨。
- 洗衣机滚筒加速、侧倾停顿回正和密集泡泡。
- 咖啡机侧置水箱、宽蒸汽、泡沫帽、杯沿泡泡与向下溢流。
- 电热水壶跳动、盖子双轴跳动、红灯与高蒸汽。
- 电饭煲深灰内锅、白米饭、米粒喷起回落、按钮周期和蒸汽。
- 手机本体高频左右晃动 + 屏幕级漫画震动线。
- 扫地机器人雷达/刷头高速转动、小圆路径和碎屑吸入。
- 扭蛋弹出、两次弹跳、双壳打开与奖品显露。
- 爆米花内部剧烈运动 + 高潮高速朝镜头喷射。
- 垃圾桶多方向屏外抛物线、最后撞盖沿二段轨迹和关盖。
- 唱片机盖板净空修正 + 屏幕级音符。
- 打印机三张模型内纸张 + 连续屏幕级过山车纸张轨迹。
- 电磁炉 14 个沸腾泡 + 18 股蒸汽 + 屏幕级沸腾补强。
- 除湿机三方向水汽汇入 + 腰部横向膨胀。
- 音箱机身随节拍压缩膨胀 + 波纹与屏幕级音符。
- 吹风机内部风线/彩条 + 屏幕级高速彩带。
- 台式电脑侧面风扇、快速键盘、扩大鼠标轨迹、顶部烟雾、多界面和蓝屏高潮。

## 现有验证证据

- `npm run build`：通过。
- 14 个家电专项脚本中，闹钟、泡泡机、除湿机、扭蛋机、吹风机、电磁炉、全量新模型、爆米花机、便携音箱、打印机、唱片机、智能垃圾桶、厨师机均通过。
- 台式电脑专项脚本原先使用旧版慢键盘节奏的固定采样点，已改为时间窗峰值验收，并增加侧面风扇与蓝屏高潮检查；需要在续作任务里重新运行。
- 全量 Playwright 共 37 个用例，在本机 SwiftShader 场景中运行 184 秒后被外层超时终止，不能计为通过或失败；需要拆成短批次运行。

## 续作任务必须完成

1. 重跑更新后的台式电脑专项脚本，确认快速键盘、侧面风扇、鼠标、蓝屏与 `stop()` 精确复位。
2. 将 Playwright 拆成 `catalog / levels / opening / transitions / visual` 五个批次，查明全量运行卡住的具体用例。
3. 在浏览器真实画面逐台观看 5.2 秒完整周期，重点验收特效方向、屏幕覆盖范围、遮挡关系和是否穿模。
4. 根据截图/录像只调幅度、时间线和生成密度；不要推翻已经完成的模型结构。
5. 所有家电必须验证 `stop()` 后精确复位，且粒子池不能持续增长或造成切关卡卡顿。
