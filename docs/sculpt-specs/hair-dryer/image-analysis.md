# SAKURA 吹风机三视图分析

## 适用性

- 三张 557/558 × 941 PNG 均通过技术探测和 reference-admission；主体单一、轮廓清晰、材质区域可辨。
- 判定：`pass`。目标为实时浏览器道具，允许用程序化曲面和 SAKURA toon 材质重建，不要求制造级尺寸。
- 类型：手持吹风机；`primaryDomain=object`；复杂度 `complex`。它是硬表面复合物体，含连续曲面喷嘴、圆筒壳体、独立手柄、控件、格栅、风扇和线缆层级。

## 观察（不含推测）

- 主轮廓：横向长圆筒机身与竖直圆角手柄构成 T 形；喷嘴从机身前端收腰后再次张开，并在出口处沿厚度方向压扁。
- 比例：机身直径约为手柄可见长度的 0.74；手柄宽约为机身直径的 0.45；喷嘴长约为机身可见长度的 0.5。
- 前端：粉色集中喷嘴、连接接缝和出口边缘；轮廓包含明显凹腰与圆角过渡。
- 后端：奶油色外环、薄荷色内环、圆形进风面及密集规则孔阵列。
- 手柄：粉色主体、奶油色底部环、圆形冷风键、长圆角滑动开关、六段锥形护线套和浅色电源线。
- 材质：奶油与粉色为中等粗糙度介电塑料，边缘有低粗糙度高光；薄荷格栅略偏硬质塑料；孔洞和内部风扇为深灰低值区域；电源线和护套更柔和、粗糙度更高。
- 身份细节：扁平喇叭形喷嘴、粉/奶油双色 T 形轮廓、薄荷进风圈、圆键与纵向滑块、阶梯护线套。

## 场景图关系

- `<nozzle, socket-overlap, motor-shell>`；喷嘴根部嵌入机身前端。
- `<handle, overlap, motor-shell>`；手柄顶部圆角肩部嵌入机身下侧。
- `<rear-intake, socket, motor-shell>`；进风组件与机身同轴。
- `<fan-rotor, inside, rear-intake>`；转轴与机身主轴一致。
- `<controls, surface-contact, handle>`；按钮和滑块位于手柄观察侧表面。
- `<cable-boot, socket, handle>`；护线套从手柄底端轴向伸出。

## 推测与不可见区域

- 内部电机、加热丝、温控保险、电气走线全部不可见，模型不宣称还原。
- 风扇叶片轮廓和转子深度被格栅遮挡，按常见轴流风扇结构推测。
- 喷嘴卡口深度、出口内部百叶及隐藏螺丝为合理制造推测。
- 参考图未显示完整电源线和插头；只保留短线段与电缆 socket，长度为玩法适配推测。
- 暖风流线与被吹动的薄荷色发束属于用途动画，不是参考图实体。

## 建模顺序

1. blockout：锁定 T 形轮廓、圆筒直径、手柄长度和喷嘴收放比例。
2. structural：拆分喷嘴、机身、后进风、手柄、控件、护线套、风扇与 sockets。
3. form：使用变量椭圆截面 loft 重建扁平喷嘴，补后环、孔阵、按钮层级和护线套。
4. material/lighting：保持奶油、樱花粉、薄荷、深腔体和软线缆五类表面，并用柔和 key/fill/rim 检查倒角。
5. interaction：滑块推进、风扇高速旋转、粉色暖风线和薄荷发束弯曲；`stop()` 精确归零。
6. optimization：孔阵使用一个 InstancedMesh；目标小于 80 draw calls、60k triangles。
