# Plug Cable Spirits · 樱色插线室

一个独立于 Sakura Crossing 主游戏的 Three.js 空间解谜原型。玩家整理中央缠绕的彩色插头电线精灵，让它们依次连接到外围家电并恢复供电。

## 玩法

- 每条彩线保持原有 X/Y/Z 三轴折线路径与统一车道间距。
- 点击出口畅通的插头后，头部先向前准备，线身像贪吃蛇一样依次经过原有 90° 拐点，尾部最后离开。
- 抽离完成后，插头沿外围弧线自动飞向固定家电接口。
- 台灯、风扇、收音机、电视、加湿器和烤面包机具有 `idle / connected / active` 三种状态与不同的启动反馈。
- 六件家电固定在屏幕外围，不随中央谜题旋转；可以直接拖到任意位置，左右移动会自动切换四分之三朝向，松手后带有短距离下落回弹。
- 家电接口会根据最近的屏幕边缘自动朝外，连接飞线持续追踪接口位置。
- 颜色到家电的映射固定，当前不增加颜色或接口匹配规则。
- 关卡按随机种子生成，并通过反向插入保证至少存在一条解法。

## 运行

```powershell
npm install
npm run dev
```

开发地址：`http://127.0.0.1:5190`

## 操作

- 按住鼠标左键拖动：旋转观察
- 鼠标滚轮：缩放
- 左键短按：理顺可用彩线
- 在家电上按住左键拖动：移动家电位置
- 重置：重新开始当前种子
- 新彩线：生成新的随机种子
